# Cimk3 的个人网站

这里是我放项目、写故事、记录日常想法的地方。

我是 Cimk3，一名计算机科学与技术专业的学生。喜欢做些小工具，也喜欢写小说。这个网站把这些零散的尝试放在一起，让它们有一个可以慢慢整理、继续生长的地方。

[进入网站](https://cimk3-me.a2034379061.workers.dev/)

## 可以在这里看到什么

**首页**提供几个精选入口，也记录最近在整理什么。第一次来，可以先读网站介绍，或挑一个感兴趣的项目、故事。

**项目**收录笔记应用、网页、桌面宠物、小游戏和我的世界附加包。部分项目附有简短案例，聊聊为什么做、可以怎样用，以及制作和更新中的一些取舍。墨记想做的是纯净无广告的快捷笔记与待办；方寸食光则希望给我的世界增添更多场景细节。

**文章**放随笔、作品上线时的想法，以及喜欢的剧集。不限定主题，想到什么就慢慢写下来。

**作品集**收录《天人合一·前传》和特别篇《如念》。作品页会介绍故事之间的关系、推荐阅读顺序，以及正文和设定资料各在哪里。

**灵感**保留还没有展开的念头。点开卡片，可以看完整图片与文字。

**资源**把学习、开发工具和游戏创作相关的链接按专题整理在一起。可以先浏览合集，也可以输入关键词查找具体资料，再前往官方或原作者的网站阅读。

**联系我**提供交流入口。如果对项目或故事有想法，欢迎来聊聊。

## 按自己喜欢的方式逛

网站支持明暗主题和可切换的背景，也可以手动播放背景音乐。手机上通过侧边菜单浏览各个页面。

界面、标题和内容简介提供中英文切换；文章和小说正文保留中文。作品介绍会尽量说明 AI 参与的部分，不把不同制作方式混在一起。

## 从一篇故事开始

想按故事开端往下读，可以从《天人合一·前传》的「第一章 大灾」开始。角色图和境界设定可以在需要时再查；也可以先独立读《如念》，从思念与重逢感受人物的另一面。

这里记录学习和创作的过程，内容会随着新的想法继续调整。谢谢你来看看。
