网络通信可以按五层理解，从上到下是应用层、传输层、网络层、数据链路层和物理层。每层处理一部分问题，并使用下一层提供的服务。

- **应用层**：规定应用之间交换什么内容、用什么格式。例如 HTTP 用于网页请求，DNS 用于域名查询。
- **传输层**：通过端口区分应用进程。TCP 提供可靠、有序的字节流传输，UDP 发送数据报，不保证送达和顺序。
- **网络层**：使用 IP 地址标识通信端点，由路由器逐跳转发数据包，使数据能够跨网络传输。
- **数据链路层**：把数据组织成帧，在相邻网络节点之间传递。以太网和 Wi-Fi 都涉及这一层。
- **物理层**：把比特编码成电信号、光信号或无线电信号，通过介质传输。

以使用 TCP 的 HTTP 请求为例，浏览器生成请求，传输层交给 TCP，网络层加上 IP 信息，链路层封装成帧，最后由物理层发送信号。接收端按相反方向逐层处理，交给对应应用。

五层模型是常见的教学划分，其中 TCP 属于传输层。资料中也常见 TCP/IP 四层模型，将底部两层合并讨论。
